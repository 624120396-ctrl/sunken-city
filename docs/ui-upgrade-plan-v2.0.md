# 沉没之城 UI 质感升级方案 V2.0
## 从"半成品磨砂玻璃"到"克苏鲁暗金质感"

---

## 一、核心差距诊断

### 当前界面（图1-8）问题

| 问题 | 表现 | 设计稿（图9-10）对比 |
|------|------|---------------------|
| **主题割裂** | 侧边栏纯黑 + 主内容区浅色，像两个世界 | 全局统一克苏鲁暗调，侧边栏融入 |
| **卡片简陋** | 扁平黑底/灰底，无边框装饰，无层次感 | 暗底+装饰边框+内发光+纸张纹理 |
| **色彩混乱** | 酒红按钮、金/白/红文字混用，无系统 | 暗金主色+血红点缀+羊皮纸文字色 |
| **装饰缺失** | 零装饰元素，页面空洞 | 触手、符文、血迹、星辰、颗粒感 |
| **排版松散** | 大量无效留白，信息密度低 | 紧凑但有呼吸感，层级清晰 |
| **按钮平庸** | 矩形纯色，无质感 | 3D浮雕感、血滴下流、边框发光 |
| **图标简陋** | Lucide默认线条图标 | 克苏鲁风格定制图标（带触手/符文） |
| **字体单调** | 全部无衬线 | 标题用衬线体（宋体/思源宋），正文无衬线 |

### 设计稿关键特征提取

**图9（深色面板参考）：**
- 深棕/暗金主调，像古旧羊皮纸浸泡在黑暗中
- 卡片四角有装饰性切角/边框线
- 头像和卡片边缘有暗金色内发光
- 血迹从标题向下流淌
- 触手装饰元素（克苏鲁头部）
- 暗纹背景（几乎不可见的纹理层）

**图10（Dashboard参考）：**
- 顶部用户面板：头像框+进度条+SP/货币显示，像游戏HUD
- 大按钮：3D感暗底，金色文字，底部有血滴效果
- 四个功能卡片区：统一的暗底卡片+图标+标题+描述
- 底部深渊广场：横幅式入口，带箭头指引
- 左侧导航：暗金色高亮条+克苏鲁风格图标

## 二、技术栈补强清单

### 已就绪 ✅
- `three.js` + `@react-three/fiber` + `@react-three/drei` + `@react-three/postprocessing` — 3D粒子/火焰
- `motion` (v12.40) — 动画系统
- `lucide-react` — 基础图标
- `FlameEffect.tsx` — 火焰粒子组件

### 需要新增 📦

| 库 | 用途 | 安装命令 |
|----|------|---------|
| `clsx` + `tailwind-merge` | 条件类名组合（如shadcn） | `npm i clsx tailwind-merge` |
| `@fontsource/noto-serif-sc` | 思源宋体（中文标题衬线） | `npm i @fontsource/noto-serif-sc` |
| `@fontsource/cinzel` | Cinzel（英文标题，符文感） | `npm i @fontsource/cinzel` |
| `react-fast-marquee` | 可选：文字/图片横向滚动效果 | `npm i react-fast-marquee` |

### CSS 能力补强（无需安装）
- `backdrop-filter` + `filter` — 已支持
- `mask-image` / `clip-path` — 用于切角卡片
- `conic-gradient` + `radial-gradient` — 用于边框发光
- `@property` — CSS自定义属性动画（chromium支持）
- `mix-blend-mode` — 用于血迹/纹理叠加
- SVG filter (`feTurbulence` + `feDisplacementMap`) — 纸张褶皱效果

## 三、设计系统重定义

### 新色彩系统

```css
:root {
  /* 基底 */
  --abyss-900: #0A0A0F;      /* 最深背景 */
  --abyss-800: #12121A;      /* 卡片底色 */
  --abyss-700: #1A1A24;      /*  elevated */
  --abyss-600: #242430;      /* 边框/分割线 */
  
  /* 羊皮纸 */
  --parchment-100: #F5F0E6;   /* 主文字 */
  --parchment-200: #E8DFD0;  /* 次要文字 */
  --parchment-300: #C4B8A5;  /* 辅助文字 */
  --parchment-400: #8A7D6B;  /* 禁用文字 */
  
  /* 暗金 */
  --gold-400: #D4A853;       /* 主金色 */
  --gold-500: #B8923A;       /* 深金色 */
  --gold-300: #E8C87A;       /* 亮金色（hover） */
  --gold-glow: rgba(212, 168, 83, 0.3); /* 金色发光 */
  
  /* 血红 */
  --blood-500: #8B1A1A;      /* 按钮/危险 */
  --blood-400: #A52A2A;      /* hover */
  --blood-glow: rgba(139, 26, 26, 0.4); /* 血光 */
  
  /* 装饰 */
  --tentacle: #1E3A3A;       /* 触手深绿 */
  --rune: #4A6741;           /* 符文绿 */
  --smoke: rgba(100, 100, 120, 0.05); /* 烟雾 */
}
```

### 新排版系统

```css
/* 标题：衬线体（克苏鲁神秘感） */
.font-heading {
  font-family: 'Noto Serif SC', 'Cinzel', 'Georgia', serif;
  font-weight: 600;
  letter-spacing: 0.05em;
}

/* 正文：无衬线（可读性） */
.font-body {
  font-family: 'Inter', 'Noto Sans SC', system-ui, sans-serif;
}

/* 符文/装饰：等宽或特殊字体 */
.font-rune {
  font-family: 'Cinzel', 'Courier New', monospace;
  letter-spacing: 0.15em;
}
```

### 全局背景策略

**方案A（推荐）：** 统一深色基调
- 侧边栏：`--abyss-900` 纯深底
- 主内容区：`--abyss-900` → `--abyss-800` 极微妙渐变（几乎不可见）
- 顶部Header：`--abyss-900` + 底部1px `--gold-400` 微光边
- 全局：极低透明度的暗纹SVG背景图（纸张纤维感）

**方案B（保守）：** 保留浅色主区
- 仅在卡片内部做深色质感
- 主内容区维持当前浅色（或稍暗的羊皮纸色）
- 风险：割裂感仍在，卡片像浮在浅色上的黑块

> **建议选A。** 设计稿9-10都是全局深色，这是克苏鲁氛围的核心。

## 四、质感层系统（核心创新）

### 1. 装饰边框卡片 `CthulhuCard`

```tsx
// 四角切角 + 双边框线 + 内发光
<div className="relative bg-abyss-800 rounded-sm">
  {/* 外层边框线 */}
  <div className="absolute inset-0 border border-abyss-600 rounded-sm" />
  {/* 内层金色细线 */}
  <div className="absolute inset-[2px] border border-gold-400/20 rounded-sm" />
  {/* 四角装饰块 */}
  <div className="absolute top-0 left-0 w-3 h-3 border-t border-l border-gold-400/40" />
  <div className="absolute top-0 right-0 w-3 h-3 border-t border-r border-gold-400/40" />
  <div className="absolute bottom-0 left-0 w-3 h-3 border-b border-l border-gold-400/40" />
  <div className="absolute bottom-0 right-0 w-3 h-3 border-b border-r border-gold-400/40" />
  {/* 顶部微光 */}
  <div className="absolute top-0 left-4 right-4 h-px bg-gradient-to-r from-transparent via-gold-400/30 to-transparent" />
  
  {/* 内容 */}
  <div className="relative p-4">{children}</div>
</div>
```

### 2. 纸张纹理叠加

```css
.parchment-texture {
  background-image: url("/images/paper-texture.png");
  background-blend-mode: overlay;
  opacity: 0.03; /* 极淡，只在边缘可见 */
}
```

### 3. SVG 血迹装饰

```tsx
// 可复用的血滴SVG组件，随机角度和长度
const BloodDrip = ({ height = 20, delay = 0 }) => (
  <svg className="absolute" style={{ animationDelay: `${delay}ms` }}>
    <path d="M0,0 Q2,${height/2} 0,${height}" 
          stroke="#8B1A1A" 
          strokeWidth="1.5" 
          fill="none"
          opacity="0.6" />
    <circle cx="0" cy={height} r="2" fill="#8B1A1A" opacity="0.4" />
  </svg>
);
```

### 4. 按钮系统重设计 `CthulhuButton`

**主按钮（暗金）：**
- 背景：`--abyss-700` → `--abyss-600` 渐变
- 文字：`--gold-400`，衬线体
- 边框：1px `--gold-400/30`，四角切角
- Hover：边框亮度提升 + 底部血滴显现（`BloodDrip`）
- 激活：内阴影 + 文字颜色变为 `--gold-300`

**危险按钮（血红）：**
- 背景：`--blood-500`
- 文字：`--parchment-100`
- Hover：背景变亮 + 边缘血光扩散

**幽灵按钮：**
- 透明背景 + `--abyss-600` 边框
- Hover：背景填充 `--abyss-800` + 边框变金

### 5. 粒子/氛围层

**Three.js 全局氛围（可选）：**
- Dashboard页面：背景漂浮暗金微尘粒子（用已安装的R3F）
- 黑水港/深渊主题页：用 FlameEffect 组件做局部火焰/迷雾
- 溺者之牌：卡牌翻转3D效果（drei的useIntersect + 旋转动画）

**CSS-only氛围（必做）：**
- 全局暗角 vignette（径向渐变遮罩）
- 随机位置的"灰尘"粒子（纯CSS动画小圆点，极低opacity）

## 七、需要用户决策

### 必须确认
1. **全局深色 or 保留浅色？**
   - A. 全局统一克苏鲁暗调（设计稿9-10风格，推荐）
   - B. 主内容区保留浅色，只做卡片深色

2. **字体选择**
   - 中文标题字体：思源宋体（Noto Serif SC）or 用户指定其他衬线体？
   - 是否引入自定义字体文件（如果有特定字体）？

3. **装饰素材**
   - 克苏鲁触手/符文/血迹等装饰元素：用CSS/SVG手绘 or 需要AI生成素材图？
   - 背景纹理：暗纹纸张是否需要生成无缝贴图？

### 可选素材需求
- 克苏鲁风格图标集（触手、眼睛、符文、古老书卷等）
- 暗金色调无缝纸张纹理背景图
- 各页面的空状态插画（克苏鲁风格）
- 角色头像框装饰素材
