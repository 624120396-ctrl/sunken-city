# 房间沉浸式体验增强方案（轻量版）

## 核心理念
不做复杂系统，只做能立刻让玩家"入戏"的小功能。

---

## 1. 场景氛围（视觉层）

### 背景氛围色
- 房间设置里可选氛围主题：
  - **阴郁** - 深蓝灰色调
  - **恐怖** - 暗红+黑色
  - **神秘** - 紫色+金色
  - **日常** - 暖黄色调
- 整个房间界面色调随主题变化

### 场景描述卡片
- 房间顶部显示当前场景描述（KP可编辑）
- 例如："图书馆地下室，潮湿的空气中有股霉味，只有一盏摇曳的油灯"
- 点击可展开/收起

---

## 2. 角色代入（身份层）

### 角色立绘/头像
- 角色卡可上传头像图片
- 房间内显示角色头像而非用户头像
- 发言时头像旁显示角色名

### "我"的视角
- 左侧状态栏显示"你是：XXX（角色名）"
- 用自己的角色名发送消息时，有特殊样式区分

---

## 3. 叙事节奏（互动层）

### 打字机效果的消息
- 玩家可以选择使用"叙述模式"发送消息
- 文字逐字出现（可调速度）
- 配合轻微的打字音效（可选开关）

### 暗骰动画
- KP暗骰时显示神秘动画（问号、阴影闪烁）
- 其他玩家看到"守秘人正在进行某种判定..."

### 疯狂滤镜
- 当角色SAN值低于阈值时：
  - 界面边缘轻微扭曲/暗角
  - 偶尔闪现文字（只有自己可见）
  - 文字轻微抖动效果

---

## 4. 简单的音效开关

### 氛围音效
- 右上角小图标，可开关：
  - 雨声
  - 风声
  - 火堆噼啪声
  - 低沉背景音（类似《血缘诅咒》的 ambience）
- 使用简单的循环音频文件
- 默认关闭，玩家自己选择

---

## 5. 聚焦模式

### 一键隐藏
- 快捷键或按钮，隐藏所有UI，只留：
  - 聊天区域（半透明背景）
  - 输入框
- 适合重要剧情时刻，减少干扰

---

## 实施优先级

| 优先级 | 功能 | 工时 | 效果 |
|--------|------|------|------|
 P0 | 场景描述卡片 | 2h | 高 |
 P0 | 角色头像显示 | 2h | 高 |
 P1 | 氛围主题色 | 3h | 中 |
 P1 | 打字机效果 | 3h | 中 |
 P2 | 疯狂滤镜 | 4h | 高（有特色）|
 P2 | 简单音效 | 2h | 中 |
 P3 | 聚焦模式 | 2h | 低 |

**总计：约18小时，分2-3周完成**

## 数据库变更（最小化）

```prisma
// Room 表新增
model Room {
  // ... existing
  atmosphere  String   @default("normal") // normal, dark, horror, mystery, warm
  sceneDesc   String?  // 当前场景描述
}

// Character 表新增
model Character {
  // ... existing  
  avatarUrl   String?  // 角色头像
}
```

---

## 关键设计原则

1. **默认不打扰** - 所有特效默认关闭，玩家主动开启
2. **轻量实现** - 不上传音频文件，使用Web Audio API生成简单音效
3. **渐进增强** - 没有这些功能，平台依然完整可用
4. **可选参与** - 不喜欢沉浸感的玩家可以完全无视
