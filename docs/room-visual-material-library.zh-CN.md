# 房间系统视觉素材库与沿用规范

日期：2026-07-07

用途：把 KP 房间页已经稳定的视觉语言沉淀为可复用素材库，供 PL 视觉版本继续沿用。后续修改 PL 时，应先对照本文，不再临时凭感觉叠加材质。

## 设计基准

房间系统的视觉方向是“沉没档案室”，不是纯黑恐怖 UI。

- 背景：使用全站统一沉没之城背景，由页面本体透出，不在房间页重复铺满廉价大图。
- 纸面：偏白做旧羊皮纸，少量边缘脏污，正文区域优先保证可读性。
- 暗面：深绿玄武岩 / 氧化铜 / 暗金线，用于 KP 工具台和顶部栏。
- 金色：用于边线、状态点、标签、仪式性按钮反馈，不大面积铺满。
- 血红：只用于危险、发送按钮、战斗和警示，不作为普通装饰色。

禁止方向：

- 黑色透明卡片。
- AI 味大面积纹理。
- 廉价重复纹理直接满铺。
- 低透明金字正文。
- 灰黑玻璃感后台面板。
- 大面积血红装饰。

## 核心素材

素材位于 `apps/web/public/ui-textures/`。

| 素材 | 用途 | 使用建议 |
| --- | --- | --- |
| `room-v6-aged-parchment-white.webp` | 主纸面 | 中央聊天区、消息卡片、输入区、PL 纸面容器 |
| `room-v6-archive-paper.webp` | 档案纸 | 左栏、PL 调查员档案、浅色侧栏底 |
| `room-v6-console-basalt.webp` | 深色工具台 | KP 右侧工具台、顶部暗材质、PL 暗色抽屉或高级工具区 |

| `room-v6-scene-ruins.webp` | 场景图 | 当前场景卡片右侧图、PL 调查案板顶部图 |

## KP 端已稳定结构

KP 桌面房间页采用三栏：

- 左：参与者册，浅色纸面，自上而下透明渐隐，底部透出全站背景。
- 中：场景卡片 + 聊天记录 + 底部输入区，浅色纸面为主。
- 右：守密人工具台，深色材质大背景，内部低磨砂小区域，按钮透明金边。

关键选择：

- 顶部四幕进度不显示。
- 房间名和房间号统一在顶部栏。
- 当前场景卡片保留金色骷髅竖线装饰。
- 当前场景右侧只保留规整的收起按钮，不堆多个按钮。
- 底部输入区、聊天框、快捷投骰必须分层清晰。
- 归档不逐条常驻挤占正文，采用统一入口或选择模式。

## 材质规则

### 纸面区域

适用：聊天区、消息卡片、PL 档案卡、状态条、输入区。

推荐组合：

- 底层使用 `room-v6-aged-parchment-white.webp`。
- 叠加极轻的暖白或纸黄色底色。
- 边缘使用少量内阴影或径向污渍。
- 阴影要轻，不能做成立体浮卡。

视觉目标：

- 远看是干净白纸。
- 近看有旧纸纤维和边缘脏污。
- 正文黑字对比明确。

### 左侧浅栏

适用：KP 参与者册、PL 调查员档案。

推荐组合：

- 使用 `room-v6-archive-paper.webp`。
- 自上而下透明渐隐。
- 磨砂度低。
- 内部卡片比外层更浅，但不做强阴影。

PL 沿用方式：

- PL 左侧“我的调查员”可以比 KP 参与者卡更整洁，但仍应使用档案纸。
- 数字类信息使用更清晰的数字字体，不强行用花体。
- 卡片边线用低对比铜金线。

### 中央聊天区

适用：KP 与 PL 共同聊天区。

推荐组合：

- 主背景：`room-v6-aged-parchment-white.webp`。
- 消息卡片：同素材小尺寸重复或 cover，但去掉明显渐变。
- 消息间距紧凑。
- 骰点结果在右侧，和正文并列。
- 系统提示保持一行。

PL 沿用方式：

- PL 不需要 KP 的管理入口，但聊天材质应与 KP 同源。
- 移动端首屏优先显示聊天与输入区，再显示调查员档案。

### 右侧暗栏

适用：KP 工具台、PL 高级工具/案板的暗色版本。

推荐组合：

- 外层大背景：`room-v6-console-basalt.webp`。
- 内部区域：低磨砂、弱边框、无强投影。
- 按钮：透明金边，不额外叠纹理。
- 激活态：提高金边和浅金透明底，不使用亮块。

PL 当前差距：

- PL 右侧“调查员案板”目前偏浅，和 KP 深色工具台不是同一类。
- 如果要贴近 KP，应改为“深色材质案板 + 浅纸线索/检定小区域”的结构。
- 如果保留浅色案板，则必须明确它是“玩家档案纸”，不是工具台同款。

## 字体规则

中文：

- 优先 `Source Han Serif SC` / `Source Han Serif CN` / `Noto Serif CJK SC`。
- 标题、姓名使用更高字重。
- 正文使用常规字重，保证清晰。

英文和数字：

- 使用 `Cinzel` / `Cormorant Garamond` / `EB Garamond` / Georgia。
- 数值列表允许使用更清晰的 UI 数字栈，但必须比花体更易读。
- 关键数值开启等宽数字排布。

## PL 沿用清单

下一步 PL 应按以下顺序处理：

1. 右侧案板材质决策：改成 KP 同源深色案板，或保留浅色档案纸但降低“工具台”感。
2. 中央聊天区完全复用 KP 的纸面材质规则，避免只显示一块平白背景。
3. 消息卡片去渐变，以纸面纹理和细边线为主。
4. PL 左侧调查员档案沿用 KP 左栏档案纸，但去掉过强阴影。
5. 移动端保持“聊天优先”，档案和案板下沉。
6. 所有 PL 按钮使用透明纸面或透明金边，除发送按钮外不使用血红。

## 实施边界

允许改：

- `apps/web/src/styles/room-visual-rebuild.css`
- `apps/web/src/pages/rooms/components/RoomPlayerView.tsx`
- 房间视觉相关文档

不应改：

- 后端逻辑
- Socket
- 骰点核心
- 战斗核心
- 私聊后端
- 生命周期写回
- admin 后台
- 官方规则/结团成长机制

权限显示继续围绕 `myRole`、`myCapabilities`、`myBinding`、`lifecycle`，不要回退到 `isCreator` 或页面局部状态猜权限。

## 当前结论

先沉淀 KP 视觉素材库是必要的。PL 版本后续不应单独另起一套材质，而应复用 KP 的：

- 顶部深色仪式石材。
- 中央偏白做旧羊皮纸。
- 左侧档案纸渐隐。
- 右侧深色低磨砂工具台。
- 透明金边按钮。

PL 可以在信息优先级上更轻、更玩家化，但材质语言必须同源。
